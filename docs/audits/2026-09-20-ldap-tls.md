# LDAP: criptare verificata inainte de autentificare

Audit local, 20 septembrie 2026. Fara publicare, deploy sau modificarea daemonului
Docker LAN. Decizia pentru Scout este explicata in
[raportul dedicat](2026-09-20-scout-exclusion.md).

## Probleme corectate

Configuratia LDAP permitea bind necriptat si dezactivarea verificarii certificatului.
Acum ambele moduri, LDAPS si StartTLS, necesita un certificat valid pentru hostul
configurat, emis de un CA de incredere, si minimum TLS 1.2. StartTLS este obligatoriu
inainte de orice parola sau cautare; refuzul upgrade-ului nu permite fallback.
Reconectarea transparenta a bibliotecii catre LDAP necriptat este blocata.
Negocierea TLS are un termen total de cinci secunde, inclusiv pentru un server
care trimite lent fragmente de date. Timeout-urile operatiilor LDAP raman active.

Hostul si portul sunt validate, iar CA-ul privat foloseste validatorul comun
(maximum 128 KiB / 32 certificate PEM, fara chei private). `tlsSkipVerify` diferit
de false este refuzat la salvare si la folosirea configuratiei existente. Parola
serviciului ramane criptata cu AES-256-GCM; nu este returnata de API.

Formularul EN/RO explica ambele moduri si migrarea. Campurile parola/CA goale
pastreaza valorile salvate, inclusiv pentru Test Connection. Eliminarea explicita
a CA-ului foloseste increderea implicita a containerului. A fost eliminata si
recomandarea din diagnostic de a dezactiva TLS prin variabila de mediu Node.
[Ghidul din produs](../../src/db/howto-content/ldap-tls.md) explica configurarea,
rotirea certificatelor si erorile; exista si varianta romana.

## Dovezi

- 351 suite, **4.519 teste reusite**, unul omis; lint fara erori.
- 25 teste de transport LDAP real pe socket-uri locale: LDAPS/StartTLS pentru
  testare, preview si autentificare, inclusiv bind-ul separat al utilizatorului.
  CA absent/gresit, nume gresit, certificat expirat si refuzul StartTLS nu trimit
  nicio parola. Blocarea reconectarii si ambele timeout-uri (tacere/date lente)
  sunt verificate separat.
- Teste Express/SQLite pentru persistenta criptata, pastrarea/eliminarea CA-ului,
  reutilizarea parolei salvate si refuzul configuratiilor invalide fara suprascriere.
- Browser real EN/RO cu CSP: payload-uri, transport, porturi si controale CA;
  help pentru toate cele 60 de pagini verificat.
- Imaginea `sha256:53b54c7d2d3aefee35fa536cfc68502e03d9e21f6ae77b4ac5797c07c6ca7126`
  a trecut smoke Linux pentru LDAP LDAPS/StartTLS, refuz CA gresit inainte de bind,
  Git SSH, mTLS provider, pornire, SQLite, Compose si persistenta secretelor dupa
  restart. Containerul izolat de test a fost eliminat.

Fixturele folosesc protocolul LDAP real, dar nu sunt o instalatie Active Directory
sau OpenLDAP de productie. Integrarea completa cu un asemenea director ramane de
verificat. Acest ID de imagine nu are inca o noua scanare de vulnerabilitati;
rezultatele imaginii anterioare nu ii sunt atribuite automat. Docker LAN 2375,
zlib, snapshot-urile istorice si inlocuirea tranzactionala a containerelor raman
probleme distincte, deschise in audit.
