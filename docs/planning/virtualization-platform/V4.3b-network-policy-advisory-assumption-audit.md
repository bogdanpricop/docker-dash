# V4.3b — Virtual network policy advisory assumption audit

| Assumption | Contract decision |
|---|---|
| a visible network is reachable end-to-end | require only provider-reported accessibility; traffic is not tested |
| absent VLAN or MTU is compliant | classify it as unknown when that evidence is required |
| a policy result can change provider configuration | keep policy input transient and read-only |
| vendor network types are interchangeable | capability-gate every endpoint and preserve unknown evidence |
| a passing policy reserves future capacity or connectivity | make no reservation and require a fresh preflight for later mutations |
