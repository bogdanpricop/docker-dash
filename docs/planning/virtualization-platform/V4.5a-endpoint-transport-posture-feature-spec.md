# V4.5a — Provider endpoint transport posture feature specification

**Status:** planned for v8.36.0 (2026-07-28)

`GET /api/providers/:hostId/endpoint-transport-posture` returns the active
provider capability-probe result, including observed reachability and duration
where available. It does not initiate a new TLS, port, certificate or transport
probe. Reachability is not evidence of authorization, feature availability,
guest connectivity or workload health. No configuration is mutated.
