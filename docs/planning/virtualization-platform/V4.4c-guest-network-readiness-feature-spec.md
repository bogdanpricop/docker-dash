# V4.4c — Guest network readiness feature specification

**Status:** planned for v8.35.0 (2026-07-28)

`GET /api/providers/:hostId/guest-network-readiness` assesses at most 100 VMs
from provider-visible NIC inventory. `ready` requires a connected NIC plus an
observed address; disconnected-only NICs are `not_ready`, and missing evidence
is `unknown`. Collection is bounded to four concurrent hardware reads.

This is evidence, not an active readiness test. It does not run guest commands,
send packets, resolve DNS, validate routing/firewall policy, mutate network
configuration, invoke CLI fallback or remediate anything.
