# V4.3d — Virtual-network placement advisory feature specification

**Status:** planned for v8.31.0 (2026-07-28)

`GET /api/providers/:hostId/network-placement-advisory` evaluates up to 500
provider-visible networks. A candidate requires explicit positive accessibility
and managed-state evidence; a negative value blocks it and missing evidence is
unknown. The advisory is capability-gated (`network.placement.read`) and
initially conditional for vSphere/Xen.

It is read-only, point-in-time evidence, not a reservation or execution
preflight. It does not prove routing, firewall policy, capacity, connectivity or
tenant isolation; it performs no mutation, traffic test, CLI fallback or
remediation.
