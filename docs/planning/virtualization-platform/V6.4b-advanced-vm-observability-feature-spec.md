# V6.4b — Advanced VM observability operations

**Release:** v8.54.0  
**Backlog:** B216–B225  
**Date:** 2026-07-29

## Outcome

V6.4b closes the observability/AIOps research batch with explainable operational
guidance and explicit governance controls. It does not collect from providers,
mutate infrastructure, silently send telemetry or infer a proven root cause.

## Operator surface

The Governance → Observability tab exposes creation, evaluation and evidence
views for every contract. Network delivery and retention deletion are separate
operator actions. Preview includes byte size and SHA-256; deletion first reports
the exact affected row counts and requires `PURGE TELEMETRY`.

## Data model and permissions

Migration 128 adds 11 `vm_observability_*` tables and the permissions
`observability_export.manage` and `telemetry_policy.manage`, granted by default
only to the site-admin governance role. Existing route-level administrator
checks and audit logging remain in force.

## Verification

The dedicated suite covers all ten backlog entries, privacy on both metric and
event intake, deterministic sampling, residency refusal, transport injection,
overlapping maintenance, table/permission counts and API/UI contract presence.
