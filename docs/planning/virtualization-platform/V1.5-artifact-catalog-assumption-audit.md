# V1.5 Assumption audit — artifact catalog

| Presupunere riscantă | Impact | Decizie implementată |
|---|---|---|
| template-ul este o VM normală | power/snapshot ar putea ținti un template | vSphere/Xen îl scot explicit din VM inventory |
| toate imaginile au UUID | ID instabil | UUID preferat; fallback derived din native ref criptat |
| storage shared apare o singură dată | duplicate Proxmox | dedupe `(kind, volid)` cross-node |
| XO are aceeași colecție în toate versiunile | incompatibilitate | `vm-templates`, fallback numai la HTTP 404 |
| orice datastore vSphere este browseable | catalogul complet eșuează | best-effort per datastore, fără anularea template inventory |
| raw Xen are templates portabile | promisiune falsă | capability explicit unsupported |
| read-only înseamnă fără date sensibile | MoRef/path pot revela topologia | native refs encrypted și omise din contract |
| un read parțial justifică ștergerea | catalog pierdut accidental | upsert fără hard-delete; răspunsul live rămâne autoritativ |
| Content Library și datastore ISO sunt același lucru | model semantic greșit | kinds separate; vAPI Content Library rămâne extensie ulterioară |
