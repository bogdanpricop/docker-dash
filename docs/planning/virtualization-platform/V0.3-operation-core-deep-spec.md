## Persistență

`provider_operations` păstrează contractul `1.0`, state, handler/action, endpoint/resource, payload criptat, request hash, idempotency hash, retry/timeout/lease, native task encrypted și outcome safe. `provider_operation_events` este jurnalul bounded pentru Activity Center. `provider_operation_locks` serializează lock scopes. `provider_operation_policies` păstrează gates globale/provider/host.

Migrarea 107 este aditivă. Niciun legacy job nu este mutat automat; convergența ACME/remediation/migration/procedures se face după ce Provider SDK mutations folosesc și validează engine-ul.

## Claim și lease

1. worker-ul selectează `queued`, `waiting_retry`, `reconciling` sau `cancel_requested` due;
2. verifică policy la momentul execuției;
3. obține toate lock-urile într-o tranzacție sau amână operația;
4. claim-ul setează owner și lease expiry;
5. progress/task binding reînnoiește lease-ul;
6. starea terminală șterge locks și lease;
7. startup recuperează `running`/`cancel_requested` cu lease expirat în `reconciling`/cancel flow.

## Retry catalog

| Policy | Attempts | Backoff | Utilizare |
|---|---:|---|---|
| `none` | 1 | fără retry | mutations ne-idempotente |
| `transient` | 3 | exponential + jitter, cap 30s | default idempotent |
| `resilient` | 5 | exponential + jitter, cap 2m | task reads/reconcile |

Doar `transient=true` sau coduri transport allowlisted sunt retryable. Auth, validation, capability și policy errors sunt permanente.

## Handler result

- valoare simplă sau `{ state: 'succeeded', result }` finalizează cu succes;
- `{ state: 'reconciling', nativeTaskRef, delayMs }` persistă bridge-ul și programează read-after-write;
- `{ state: 'unknown', result }` cere operator;
- throw cu `transient=true` aplică retry policy;
- timeout intră în reconciliation dacă handler-ul o implementează, altfel `unknown`.

## Cancel

Pending work fără attempt este anulat local. Pentru running/native work, engine-ul transmite AbortSignal și apelează `cancel`. Numai `{ confirmed: true }` produce `cancelled`; lipsa confirmării produce `unknown`, cu evidence și fără retry automat.

## Bounds

- request plaintext maximum 64 KiB înainte de encryption;
- safe result/event maximum 16 KiB;
- maximum 8 lock scopes, 200 caractere fiecare;
- operation type/action maximum 80;
- error code 80, error message/reason 240;
- events list maximum 500 per request;
- operation list maximum 500.

## Rollback

Imaginea V0.2 ignoră tabelele 107. Worker-ul V0.3 este oprit înainte de închiderea DB. Rollback-ul imaginii nu șterge operații; la revenirea la V0.3 acestea sunt reconciliate după lease expiry.
