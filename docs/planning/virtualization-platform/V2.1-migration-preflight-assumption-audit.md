# V2.1 — Migration preflight assumption audit

| Assumption | Decision |
|---|---|
| Host inventory implies migration compatibility | False; inventory only creates candidates and provider checks decide evidence. |
| VMotion CPU/software compatibility proves storage and network reachability | False; those remain separate checks or explicit unknown warnings. |
| Same storage ID on Proxmox means shared storage | False; target availability and storage `shared` evidence are retained separately. |
| Sufficient total RAM means sufficient available RAM | False; free/used observations plus a 10% safety reserve are used. |
| A running VM can always migrate live | False; power state is necessary but not sufficient. |
| A stopped VM has zero migration duration | False; estimated downtime is zero only as additional outage, while transfer duration remains reported. |
| XO host/pool topology is equivalent to XAPI compatibility | False; XO fallback is labeled heuristic and low confidence. |
| Raw Xen can plan another host | False; standalone toolstacks have no fleet placement boundary. |
| Preflight authorizes migration execution | False; V2.1 has no mutation route. |
