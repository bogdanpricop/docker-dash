# V4.5b — Consolidated network evidence dashboard feature specification

**Status:** planned for v8.37.0 (2026-07-28)

## Goal

Present the already-collected virtual-network evidence in one compact operator
summary without broadening collection, authority, or claims.

## Scope and safety boundary

- Uses only the Network Posture page's existing request results: posture,
  attachment topology, IP observations, conflict candidates, readiness, and the
  existing provider capability-probe outcome.
- Shows unavailable sources explicitly and never treats them as healthy or empty.
- Does not invoke provider, guest, TLS, certificate, port, DNS, packet, or CLI
  operations beyond the calls the page already makes.
- Cannot persist a setting, execute a mutation, reserve a network, or remediate
  any finding.

The dashboard is evidence navigation, not a connectivity, routing, isolation,
policy-enforcement, or IP-ownership verdict.
