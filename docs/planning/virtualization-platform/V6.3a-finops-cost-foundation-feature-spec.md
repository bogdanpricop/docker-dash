# V6.3a — FinOps cost foundation

**Release:** v8.60.0  
**Backlog:** B276–B285  
**Date:** 2026-07-29

## Outcome

V6.3a introduces a vendor-neutral rating foundation for mixed virtualized
infrastructure. It records what was allocated and used, applies explicit
versioned rates, maps technical tags to business dimensions and produces
transparent showback plus ERP-ready exports. It never changes provider
resources and never creates a billing transaction.

## Data model and permissions

Migration 134 adds eight stores: resource ledger, cost models, allocation rules,
resolved allocations, rating runs, rated usage lines, chargeback exports and
budgets. Ledger observations and rating runs are append-only at the service
boundary. Cost models are immutable name/version records with a stable content
hash, three-letter currency, confidence class, credential-free HTTPS source and
complete effective window.

Four site-admin permissions are added: `finops_ledger.manage`,
`finops_cost.manage`, `finops_reporting.manage` and `finops_budget.manage`. The
production governance permission catalog therefore reaches 44 entries.

## Rating semantics

A rating run selects explicit model IDs and a bounded period. All selected
models must use one currency and cover the complete period. Only ledger entries
fully contained by that period are rated. Model scope may be global or match a
provider, site, project or cost center. The input hash includes ordered ledger
and model hashes, making an identical run idempotent.

Private-cloud cost is a weighted fraction of declared fleet CPU/RAM capacity.
License cost uses the declared licensed unit and billing period. Storage,
network and GPU models preserve their component calculation inside each line's
formula. Rounding happens at six decimals and the unrounded calculation inputs
remain available in formula evidence.

Tag rules run from highest to lowest priority and only fill dimensions not
already supplied by a more specific rule. Coverage is reported as allocated,
partial or unallocated. No rule writes tags back to a provider.

## Showback, export and budgets

The showback view aggregates cost by category, cost center and confidence while
retaining each resource/model line. Chargeback generation deterministically
serializes those same lines as CSV or canonical JSON, stores checksum, row count
and total, and reports `billingTransactionCreated: false` at every boundary.

Budgets support global, cost-center, business-unit, application, environment,
project and site scopes. Their monthly or quarterly amount is prorated to the
rating interval for comparison. The result exposes spent, remaining and
utilization; it deliberately creates zero alerts because threshold and forecast
notifications belong to B286.

## Control surface and verification

Governance → FinOps exposes the ten capability contracts, immutable ledger,
cost model versions, tag-resolution state, showback lines, downloadable
chargeback evidence and budget utilization. All write operations are audited.

The dedicated suite covers all eight stores and four grants, ledger
deduplication/bounds/secret rejection, all five cost families, priority tag
allocation, exact multi-model rating, hash idempotency, GPU fail-closed behavior,
deterministic CSV export, scoped monthly/quarterly budgets and the explicit
zero-billing side-effect guarantee.
