# V5.8b — Signed connector marketplace and integration contracts

**Release:** v8.73.0

**Backlog:** B406–B415

**Date:** 2026-07-30

## Outcome

This batch completes the provider SDK/connectors backlog with signed discovery,
secret-free configuration and normalized evidence. It intentionally separates
the integration control plane from plugin-owned network execution: this API
registers exact contracts and prototypes but performs no connector request.

## Signed marketplace

- B406 verifies a detached Ed25519 signature over canonical marketplace JSON.
  Publisher, version, support level, domains, products, documentation URL and
  exact allowed HTTPS hosts are bound into the manifest hash.
- Re-registering an entry replaces its signed contract atomically. A connector
  cannot use a domain or product absent from the current signed manifest.

## Enterprise integration contracts

- B407 CMDB sync plans support NetBox, ServiceNow and GLPI-style products,
  import/export/bidirectional direction and per-field `docker-dash`/`cmdb`/
  `manual` ownership. Ownership mismatch and explicit conflicts block the plan.
- B408 ITSM links retain ticket URL, evidence links, approval state and an exact
  evaluated change window. Only approved, in-window evidence is `ready`.
- B409 emits a normalized `urn:docker-dash:event:1.0` envelope for Splunk,
  Elastic, Sentinel or syslog adapters and persists no raw payload.
- B410 accepts Vault, Key Vault, Secrets Manager and 1Password URI references.
  Secret values, credentials, authorization fields and private keys fail closed.
- B411 binds IP allocation/reservation/release and A/AAAA/PTR lifecycle plans to
  a resource, ownership token and expected external version. It exposes no apply.
- B412 normalizes Veeam, Commvault, Rubrik and HYCU job/recovery-point visibility.
- B413 monitoring targets require a signed exact HTTPS host plus metric and
  label allowlists; optional authentication points to a stored secret reference.
- B414 Kafka, NATS, AMQP, SNS and SQS publications use a schema-bound normalized
  envelope and remain in the `planned` state.
- B415 registers exact OpenAPI host/method/path/risk/query/body allowlists.
  Prototype requests return only field lists and hashes and never call the host.

## Persistence and authorization

Migration 147 adds ten integration tables and two governance permissions:
`connector_marketplace.manage` and `connector_integrations.manage`. All APIs are
administrator-only and every accepted write is audit logged. The Connector
Marketplace tab exposes signature/support evidence, domain/product coverage and
a per-domain contract ledger with zero implicit network calls or mutations.
