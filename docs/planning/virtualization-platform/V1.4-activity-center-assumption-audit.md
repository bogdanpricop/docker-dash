# V1.4 Assumption audit — Activity Center

| Ipoteză | Risc | Control |
|---|---|---|
| rolul UI este suficient pentru cancel | operator fără grant pe host mută o resursă | server calculează și revalidează effective `operate` |
| request cancel înseamnă cancelled | providerul refuză sau termină normal | `cancel_requested` intermediar; confirmare provider sau `unknown` |
| orice task nativ este cancelable | semantică diferită vSphere/XAPI/PVE | handler capability și fail-closed outcome |
| progress 100 înseamnă success | XAPI avertizează să fie folosit status | state/verification este autoritativ, progress doar prezentare |
| raw native ref ajută operatorul | leak de provider intern și scope confusion | afișează presence/state, păstrează ref encrypted |
| `unknown` poate fi rezolvat prin presupunere | lock release după rezultat greșit | admin-only, evidence, typed operation ID, conditional DB update |
| username este denormalizat sigur în job | rename/stale identity | read-time LEFT JOIN, ID persistent rămâne autoritativ |
| mouse click este suficient | Activity Center inaccesibil din tastatură | row role/tabindex + Enter/Space |
| client-side search poate extinde access | date nepermise ajung în browser | server filtrează host access înaintea răspunsului |
