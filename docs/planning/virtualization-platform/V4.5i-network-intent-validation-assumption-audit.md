# V4.5i — B125 assumption audit

| Assumption | Failure mode | Decision/evidence |
|---|---|---|
| Syntactically valid CIDRs cannot conflict | two networks overlap or consume a reserved range | compare canonical numeric ranges across all resources |
| Gateway family match is enough | gateway is outside subnet or is network/broadcast | require containment and exclude unusable IPv4 endpoints |
| Duplicate VLAN/VNI is globally invalid | legitimate reuse across isolated domains is blocked | VLAN uniqueness is L2-domain scoped; VNI uniqueness is fabric scoped |
| A more specific route shadows a broader one | valid longest-prefix routing is rejected | only exact destinations with duplicate/conflicting next hops are blockers |
| Missing evidence means no conflict | incomplete inventory receives false `pass` | incomplete/stale evidence forces `unknown` |
| String equality is CIDR equality | alternate IPv6 spellings evade collisions | parse to canonical family/start/end BigInt ranges |
| A validation remains valid after intent changes | stale approval reaches executor | both normalized intent and validation receive immutable hashes |
| Validator may call providers to fill gaps | unexpected network load and secret exposure | pure local validation; caller supplies bounded evidence |
