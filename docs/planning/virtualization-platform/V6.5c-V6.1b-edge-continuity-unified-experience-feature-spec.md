# V6.5c / V6.1b — Edge continuity and unified infrastructure experience

**Release:** v8.67.0

**Backlog:** B346–B355

**Date:** 2026-07-29

## Outcome

This batch closes the remaining edge-continuity items and makes the first five
common operator-experience features concrete. All aggregate views are filtered
by endpoint access. Missing or stale evidence is reported as unknown rather
than promoted to healthy.

## Edge controls

- Disaster declarations require an allowlisted local agent runbook, freeze all
  new edge mutation plans and queue notification references. Four-eyes,
  typed-site confirmation releases the freeze.
- Backup seeding stores signed chunk manifests and replay-safe continuation
  checkpoints. The API does not read or transfer backup data.
- Compliance snapshots reduce evidence to control/state counts; raw digests are
  never included in the fleet response.
- Rack, power, network and storage fault domains expose coverage and replica
  risks. The assessment has no placement executor.
- Enrollment tokens are single-use, expire within 15 minutes and bind exact
  manufacturer/model/serial/TPM claims. The agent owns its key pair; approval
  persists only certificate fingerprints and identity hashes.

## Common experience

- `/api/experience/home` returns permission-filtered endpoint health, persisted
  workload coverage, risks, FinOps evidence and recent operations.
- `/api/experience/navigation` exposes an availability reason for each
  provider-dependent page and the SPA shows only pages backed by a permitted,
  active endpoint that is not explicitly unhealthy.
- DetailShell can enforce the canonical Overview/Actions/Tasks/Events/Audit
  contract while preserving resource-specific tabs.
- `/api/experience/actions` returns independent capability, policy, state and
  endpoint-permission blockers.
- Provider operations include canonical API, event, activity and resource
  links; Activity Center summarizes active progress, failures, successes and
  safely cancellable work.

## Safety boundaries

- No disaster notification, backup transfer, topology placement or provider
  mutation is performed centrally by these features.
- The infrastructure home performs no live provider calls and declares its
  evidence coverage.
- Enrollment never accepts inline credentials or returns certificate private
  keys.
