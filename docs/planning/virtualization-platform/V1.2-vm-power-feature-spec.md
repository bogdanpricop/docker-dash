# V1.2 Feature spec — Safe VM power operations

## Obiectiv

Operatorul execută start, clean shutdown, clean reboot, force off și force reboot prin același contract pentru Proxmox, vSphere și Xen. Orice mutation trece prin preflight, confirmare, policy/RBAC/capability gate, operation lock, task persistent și post-action verification.

## Scope

- capability evidence real pentru power pe cei trei provideri;
- per-resource allowed actions derivate din state/tools/native allowed operations;
- single și bulk preflight, maximum 20 VM-uri per request;
- `Idempotency-Key`, plan hash și TTL;
- confirmare explicită pentru toate operațiile și typed VM name pentru force;
- durable operation `vm.power`, fără retry automat al mutation-ului;
- native task bridge pentru PVE UPID, vSphere Task MoRef și Xen XAPI/XO tasks;
- reconciliation și post-action state verification;
- UI enable numai când feature flag, capability, state, policy și permission permit;
- audit pentru single/bulk submission.

## Anti-scope

- create wizard B031 rămâne V1.6: depinde de template/image inventory, storage/network plan și quotas;
- pause/suspend rămân vendor actions până la extinderea capability catalog;
- nicio mutation comună durabilă pe raw Xen: domid-ul este tranzitoriu și raw toolstack nu oferă task/reconciliation identity portabilă; acțiunile native existente rămân separate și explicit limitate;
- nicio operație disposable live pe staging ESXi fără o VM desemnată explicit;
- niciun retry automat pentru reboot sau force.

## Acceptance

- preflight stă la baza submit-ului și un plan schimbat este respins 409;
- force cere numele exact al VM-ului;
- două operații pe aceeași resursă sunt serializate;
- referințele native/task sunt encrypted și nu apar în API/audit;
- provider timeout după submit intră în reconciliation, nu repetă mutation-ul;
- success cere state post-condition sau task evidence plus state post-condition;
- bulk este all-or-none la creare și raportează un operation ID per VM;
- flag-ul `DD_PROVIDER_VM_POWER` este implicit false.
