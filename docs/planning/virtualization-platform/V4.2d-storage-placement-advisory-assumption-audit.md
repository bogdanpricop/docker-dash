# V4.2d — Storage placement advisory assumption audit

| Assumption | Counterexample | Contract decision |
|---|---|---|
| reported free capacity is a reservation | another workload can consume space immediately | label result advisory-only and require execution-time revalidation |
| an active storage is not in maintenance | providers can omit or separately report maintenance | missing/unrecognized state remains unknown |
| all Proxmox storage accepts VM disks | ISO/template-only storage is visible in inventory | require positive `images` content evidence when classes are reported |
| a capacity pass proves every safety condition | accessibility and maintenance can invalidate placement | evaluate all applicable signals independently |
| an arbitrary requested size is harmless | huge or malformed values can overflow policy logic | enforce 64 MiB–64 TiB integer bounds |

## Audit probes

1. Prove requested capacity includes the configured headroom exactly.
2. Prove inaccessible, maintenance and capacity-short targets are blocked.
3. Prove missing evidence is unknown rather than candidate.
4. Prove a Proxmox target without `images` support is blocked.
5. Prove no endpoint writes, reserves capacity or accepts an unbounded size.
