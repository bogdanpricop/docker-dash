## Deployment method

Each host verified and extracted the same checksummed Git archive, then built
the production Docker target with `APP_VERSION=8.59.0`. The application-only
recreate used the base project directory and environment while the release
compose file selected the immutable image:

```sh
APP_VERSION=8.59.0-d8d4d4a docker compose \
  --project-directory "$BASE" --env-file "$BASE/.env" \
  -f "$RELEASE/docker-compose.yml" up -d --no-build --no-deps app
```

The rollout retained an automatic app-only rollback to the immediately
preceding V0.3e release. No rollback was required.
