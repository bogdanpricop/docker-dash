# V4.3e — Network configuration drift baseline feature specification

**Status:** planned for v8.32.0 (2026-07-28)

An authorized host administrator can explicitly save a baseline of normalized,
provider-visible network evidence. Later host-view reads compare accessibility,
managed state, bridge, VLAN ID and MTU. An absent baseline is `unbaselined`; it
is never represented as in sync. Provider-native references are not stored.

Baseline creation and comparison are read-only for the provider. They perform no
network mutation, traffic test, guest query, CLI fallback or remediation.
