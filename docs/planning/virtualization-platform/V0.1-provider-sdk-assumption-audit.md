# V0.1 Assumption audit

| ID | Presupunere | Risc dacă este falsă | Verificare înainte de implementare |
|---|---|---|---|
| A01 | `daemon_type` este sursa canonică pentru adaptor | adaptor greșit/credential leak | inspectare schema, host routes și migrations |
| A02 | host access middleware funcționează pe path params | cross-host read | route test cu user limitat |
| A03 | Proxmox `/version` nu necesită CSRF pentru token | probe eșuat | fixture și endpoint real |
| A04 | vSphere ServiceContent permite distingerea vCenter/ESXi | variant fals | fixture ambele produse; fallback unknown |
| A05 | Xen `info()` nu produce mutation | side effect | review XO/XAPI/raw clients |
| A06 | client caches pot fi invalidate extern | stale capability | expose/adapt invalidate hooks |
| A07 | legacy frontend tolerează keys suplimentare | UI regression | API/UI tests și no-shape-change policy |
| A08 | 60s TTL este suficient de scurt pentru edition/config changes | stale UX | refresh admin și invalidate la save |
| A09 | feature catalog poate rămâne sub 256 KiB | response cap | serialization size test |
| A10 | provider errors pot fi clasificate fără text sensibil | leak sau messages inutile | redaction tests cu tokens/URLs/XML |
| A11 | full test suite rulează în timpul unui batch | regresii neobservate | CI/local baseline înainte de code |
| A12 | staging poate construi imaginea din branch | deploy blocat | preflight git/build/disk pe host |
| A13 | VPS host key este stabil și verificat | MITM/host greșit | confirmare fingerprint out-of-band |

Presupunerile A02, A06, A07, A10, A12 și A13 sunt release blockers. Celelalte pot produce un scope adjustment documentat.
