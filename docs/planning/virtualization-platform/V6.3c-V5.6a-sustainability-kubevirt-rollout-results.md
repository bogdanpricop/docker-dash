## Deployment and rollback method

Both hosts checksummed and extracted the same Git archive, then built the
production target with `APP_VERSION=8.62.0`. Only the app was recreated:

```sh
APP_VERSION=8.62.0-9362b9f docker compose \
  --project-directory "$BASE" --env-file "$BASE/.env" \
  -f "$RELEASE/docker-compose.yml" up -d --no-build --no-deps app
```

The verification scripts retained an app-only rollback to v8.61.0. All checks
passed and no rollback was required.
