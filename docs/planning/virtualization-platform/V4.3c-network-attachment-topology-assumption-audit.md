# V4.3c — VM network attachment topology assumption audit

| Assumption | Contract decision |
|---|---|
| a shared network attachment proves reachability or isolation | report attachment evidence only; make no connectivity claim |
| provider-native network IDs are safe to expose | replace them with host-scoped opaque identities |
| every VM NIC can always be read | report hardware failures and truncation as partial coverage |
| topology needs guest inspection or test traffic | read provider NIC inventory only |
| grouping can safely mutate network configuration | expose no mutation, reservation or remediation path |
