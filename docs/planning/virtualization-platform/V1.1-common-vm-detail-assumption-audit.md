# V1.1 Assumption audit

| Presupunere | Risc | Decizie |
|---|---|---|
| Lista VM este echivalentă cu detail complet | câmpuri inventate | detail separă overview/hardware de tabs indisponibile |
| Canonical ID poate fi căutat global | cross-host leak | host access înainte de răspuns; mismatch devine 404 |
| Cache-ul poate păstra raw provider data | secret/native-ref leak | persistă numai normalized resource JSON validat |
| Un capability supported înseamnă action activ | mutation prematură | V1.1 adaugă întotdeauna `ACTION_NOT_ENABLED` |
| Disks/NICs lipsă înseamnă listă goală | operatorul crede că VM nu are device-uri | `available=false` și reason explicit |
| Search poate interoga toate hypervisor-ele la fiecare tastă | load/cascadă | command palette caută exclusiv snapshot cache |
| Snapshot cache este fresh | decizii pe date vechi | `observedAt` vizibil și refresh explicit |
| Viewer poate vedea toate VM-urile | tenant leak | `requireHostAccess(view)` și filtrare host permission în search |
| Native ref este util în URL | credential/topology leak | URL conține numai `ddr_vm_*` |
| Activity Center trebuie duplicat | inconsistență | detail include bounded summary și deep link către API-ul persistent |
