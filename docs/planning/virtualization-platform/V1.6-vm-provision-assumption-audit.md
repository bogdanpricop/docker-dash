# V1.6 Assumption audit — clone/create-from-template

| Presupunere riscantă | Impact | Decizie implementată |
|---|---|---|
| un artifact ID poate intra în operation engine ca resource comun | slăbirea identity validation | kind dedicat `artifact`, regex exclusiv `dda_art_*` |
| prezența în catalog autorizează clone | privilege escalation | admin + host operate + writeable + capability + release flag + policy |
| un plan vechi este suficient | storage/template drift | re-preflight la submit și live revalidare în handler |
| Idempotency-Key permite retry al clone-ului | duplicate VM | key dedupe la create, dar handler non-idempotent/no replay |
| numele VM este unic la toți providerii | rezultat ambiguu | lock cross-template pe nume și verificare exact-unică |
| `auto` are aceeași semantică | cost/chain neașteptat | Proxmox/vSphere full; XAPI linked; effective mode afișat |
| linked clone este independent | pierdere la source/storage chain | warning explicit; mode selectat și auditat |
| vSphere clone are nevoie numai de template | InvalidArgument/placement greșit | folder, resource pool și datastore live obligatorii |
| orice datastore vSphere este valid | task failure/maintenance | accessible și non-maintenance; source default |
| XAPI clone produce direct VM deployată | VM fără disks provisionate | stage distinct clone/copy → provision |
| task ref se persistă mereu înainte de crash | task orfan/dublu submit | recovery după target name/VMID; XAPI provision are checkpoint pre-submit și `current_operations` recovery |
| XO `vm.create` din JSON-RPC este echivalent cu REST | API privat/version drift | niciun fallback ghicit; XO REST rămâne unsupported |
| task cancel are aceeași garanție | stare fals cancelled | numai Proxmox confirmabil; altfel unknown |
| create și power-on pot fi atomic aceleași operații | blast radius/diagnostic dificil | VM powered-off; start separat |
| template Proxmox este VM runnable | power/snapshot pe template | `template=1` exclus din common VM inventory |
| un timeout înseamnă failure | VM poate exista deja | `unknown` după deadline și lock păstrat |
