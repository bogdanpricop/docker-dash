# V6.6b — Hardware devices and accelerator control plane

**Release:** v8.71.0

**Backlog:** B386–B395

**Date:** 2026-07-30

## Outcome

This batch adds normalized, host-scoped device evidence and safe control-plane
planning for PCI, SR-IOV, GPU/vGPU and accelerator reservations. It deliberately
does not implement provider attach, detach, reconfiguration or capacity holds.

## Evidence contracts

- B386 records memory tiers with capacity/use, optional hit rate and bounded
  workload impact; impossible use above capacity is rejected.
- B387 records unique PCI functions and addresses, IOMMU group/NUMA locality,
  ACS/reset readiness, driver, health, mappings and valid PF/VF relationships.
- B390 records GPU model, memory, driver, health, MIG support and licensed
  profile capacity linked to a known PCI function.
- B393 records idempotent, timestamped SM/memory/encoder utilization, ECC count
  and bounded throttle reasons only for GPUs in the latest host snapshot.
- B395 records USB identity, owner, mapping and host-bound/remappable mobility,
  then derives migration, existing-map and missing-owner caveats.

Snapshots are capped at 512 KiB, reject credential-shaped fields recursively,
are canonicalized and retain a SHA-256 evidence identity.

## Plans and reservations

- B388 creates PCI passthrough plans only when health, provider allocation,
  function-level reset and IOMMU isolation evidence is ready. Plan release is a
  control-plane state transition with `infrastructureMutated: false`.
- B389 auto-selects a free VF from an optional PF pool and excludes host-local
  planned allocations.
- B391 creates full-GPU plans with NUMA, migration and HA caveats.
- B392 verifies licensed profile capacity, permits the reported number of
  shared-profile plans and prevents full-GPU/vGPU conflicts.
- B394 stores host/device/profile/tenant/time-bound reservations. Full-device
  windows conflict with every profile window; expired rows leave the active
  schedule automatically.

All plans are immutable and hash-bound. Their contract sets `applyEndpoint` to
null and `providerMutationsStarted` to zero.

## Persistence, authorization and UI

Migration 145 adds immutable device snapshots, allocation plans, accelerator
metrics and reservations plus `hardware_devices.manage`, granted to the
site-admin governance role. The existing administrator-only Hardware &
Performance surface exposes inventory inspection, plan creation/release,
telemetry and reservations. Every accepted write is audit logged.
