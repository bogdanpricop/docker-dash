# V4.4b — IP conflict candidates feature specification

**Status:** planned for v8.34.0 (2026-07-28)

`GET /api/providers/:hostId/ip-conflict-candidates` groups the bounded,
provider-visible IP observations already collected by V4.4a. An address observed
on more than one VM NIC is a candidate only. NAT, stale guest-tools observations,
multi-homing and provider semantics can produce repeated addresses.

The endpoint performs no active discovery, ARP/ping, DHCP/IPAM lookup, guest
command, mutation, CLI fallback or remediation.
