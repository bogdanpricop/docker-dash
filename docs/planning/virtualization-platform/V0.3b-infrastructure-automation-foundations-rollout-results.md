## Rollback exercise

The first LAN activation reached healthy state, but a post-deploy verification
query incorrectly used SQL identifier quotes for the literal table type. The
deployment trap automatically restored `8.54.0-4387d9f`, which returned healthy
with zero restarts. The verification query was corrected to parameter binding
and the already-built 8.55.0 image was reactivated successfully. The fault was
in rollout validation, not in the application or migration.

## Safety boundary retained

Plan acceptance records reviewed intent and schedules no provider mutation.
Compensation is a deterministic preview only. Secret-like manifest fields are
rejected recursively, native-operation ciphertext is not returned, and
authoritative storage/network deletion remains blocked until B236 safeguards.
