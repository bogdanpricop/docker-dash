## Live provider evidence

Both active LAN vSphere endpoints initially returned `ECONNRESET`. After the
LAN application restart re-established runtime connectivity, a deployed
read-only canary succeeded on host 5 (`ESXi-6`) and host 6 (`Socrate`). The
canary invoked the same capture service under an existing administrator record;
route authorization/audit behavior remains covered by focused API tests because
no reusable browser/API session was available.

| Host | B118 | B120 | B121 | Safety work |
|---|---|---|---|---|
| ESXi-6 | 11 IP observations, captured | 2 paths, `unknown` | 1 bond, `unknown` | 0 mutations/probes/guest commands |
| Socrate | 9 IP observations, captured | 2 paths, `unknown` | 1 bond, `fail` | 0 mutations/probes/guest commands |

The B120 results remain `unknown` because segment-only evidence cannot prove an
end-to-end path or DF behavior. The Socrate B121 failure is retained as an
observed finding; no failover, link change or remediation was started.

The first v8.91.0 canary exposed that a dependency rebuild rounded its source
cutoff to the start of the current minute, leaving snapshot 1 empty even though
the address observations were valid. The immutable record was not deleted.
v8.91.1 removed the backward rounding, bound the rebuild to the source timestamp
and added two regressions. The repeated live canary produced latest snapshot 3
with 6 nodes, address-observation cursor `[4,3,2,1]`, no inferred edges and hash
`7a70e36eca3ec05543aeffb89dd7173f61f4da931014f0ffd5c48ff11d2e3dca`.

Final LAN evidence counts are 4 address observations, 3 dependency snapshots,
4 MTU assessments and 4 Bond/LAG observations. VPS has no active provider and
remains at zero for these stores. Temporary local and remote release/source
archives were removed; both database backups were intentionally preserved.

Browser smoke, DNS/flow adapters, end-to-end/DF evidence, distributed LACP and
counters, non-vSphere physical collectors and the unchanged external gaps of
the other seven batch features remain explicit. No feature is promoted from
`Partial`.
