# V0.1 Preflight checklist

## Repository

- [ ] baseline Xen/research/plan publicat și deployat;
- [ ] branch/PR checks verzi;
- [ ] worktree curat înaintea V0.1;
- [ ] full suite baseline salvată;
- [ ] current `/api/system/info` fixture capturat.

## Code audit

- [ ] toate locurile care definesc `capabilities` inventariate;
- [ ] host access și host ID middleware confirmate;
- [ ] update/delete/reconnect invalidation paths inventariate;
- [ ] clients Proxmox/vSphere/Xen și close semantics inspectate;
- [ ] metrics registry pattern existent reutilizat;
- [ ] feature flag conventions confirmate.

## Fixtures

- [ ] Proxmox version success/auth fail/timeout;
- [ ] vCenter ServiceContent;
- [ ] standalone ESXi ServiceContent;
- [ ] Xen Orchestra info/capabilities;
- [ ] XAPI JSON și XML;
- [ ] raw `xl` și legacy `xm`;
- [ ] secret-bearing errors pentru redaction.

## Deploy environments

- [ ] staging SSH host key valid;
- [ ] staging git/build path și compose project confirmate;
- [ ] staging DB backup și previous image tag;
- [ ] VPS fingerprint verificat out-of-band;
- [ ] VPS path/compose project și previous image tag confirmate;
- [ ] health checks înainte de deploy;
- [ ] rollback command verificat fără execuție.

## Go/no-go

V0.1 începe numai după închiderea blockerelor din assumption audit. Implementarea poate continua local dacă un singur mediu de deploy este blocat, dar batch-ul nu este marcat complet până când mediile autorizate au fost actualizate sau blocarea este consemnată explicit de operator.
