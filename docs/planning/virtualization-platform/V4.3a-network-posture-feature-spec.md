# V4.3a — Virtual network posture feature specification

**Status:** shipped in v8.28.0 (2026-07-28)

Network Posture is a host-view, read-only projection of provider network inventory.
It reports accessibility, management state, bridge/backing, VLAN and MTU only when
the active provider returns those observations. It does not test traffic, routing,
firewall policy or tenant isolation, and exposes no mutation surface.

`GET /api/providers/:hostId/network-posture` is conditionally available on vSphere
and supported Xen management planes via `network.health.read`; Proxmox fails closed
until a common global bridge-inventory contract is released.
