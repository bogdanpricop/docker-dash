# V4.2e — Storage policy advisory assumption audit

| Assumption | Counterexample | Contract decision |
|---|---|---|
| omitted telemetry satisfies a policy | providers often leave shared/free/accessibility fields absent | omitted evidence is unknown, never compliant |
| a compliance view should become provider policy | an unreviewed browser choice could change production storage | policy remains transient and read-only |
| free capacity alone proves target usability | inaccessible storage can still report old capacity | accessibility is always a separate required signal |
| any minimum free value is safe to calculate | malformed or huge input can overflow/obscure the result | accept only integer values from 0 to 64 TiB |
| shared requirement is universal | some providers cannot report shared state | absence is unknown rather than a fabricated pass/fail |

## Audit probes

1. Prove missing shared/free/accessibility evidence is unknown.
2. Prove a negative provider value is noncompliant.
3. Prove minimum free-space bounds reject invalid input.
4. Prove operator choices are response-only and no mutation endpoint is called.
5. Prove unsupported policy capability fails closed.
