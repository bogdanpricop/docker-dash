# V4.4l — Operational qualification for the first ten Partial features

**Release:** v8.85.0
**Exact batch:** B015, B045, B090, B096, B104, B118, B119, B120, B121, B123

## Purpose

These implementations were included in v8.80.0, but their tracking still mixed
release inclusion with evidence that requires a browser, approved data-plane
adapter, provider-native collector or disposable mutation canary. This release
adds one endpoint-scoped, read-only qualification envelope so operators can see
the difference between delivered schema, observed runtime evidence and work
that is genuinely still outstanding.

## Contract

`GET /api/providers/:hostId/operational-qualification` returns exactly the ten
IDs above. Every item contains:

- implementation and qualification releases;
- required-table presence without attempting migration repair;
- bounded record counts and latest evidence time for the current endpoint or
  explicit global/user scope;
- mutation flag state for B045 and the provider-specific B104 adapter;
- stored zero-call/zero-mutation counters for passive network evidence;
- explicit outstanding browser, adapter, collector, active-runner and canary
  requirements;
- a deterministic SHA-256 evidence hash that excludes response generation time.

The Provider Security page renders the envelope as operational evidence. Empty
tables are `not_observed`, never successful. The B096 adapter capability is
reported without resolving a secret or initiating a repository connection.

## Safety boundary

The endpoint starts zero provider mutations, network calls, external commands,
browser runs or active probes. It neither authorizes B045/B104 execution nor
changes their default-off flags. It does not close any `Partial` item whose
browser, provider, data-plane or canary evidence is still absent.

## Acceptance

- exact ordered ID set and count of ten;
- schema-missing and no-observation states remain explicit;
- per-user B015 evidence does not leak another user's saved views;
- evidence hash is stable across reads with identical persisted state;
- B045/B104 release flags are displayed as default-off unless explicitly set;
- UI escapes feature/gap content and labels browser evidence as unrecorded;
- focused service, page and repository adapter-capability tests pass.
