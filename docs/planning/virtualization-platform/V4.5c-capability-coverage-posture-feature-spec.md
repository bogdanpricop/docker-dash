# V4.5c — Provider capability coverage posture

**Release target:** v8.38.0 (2026-07-29)

The Provider Security Posture page summarizes declared SDK capability states for
one visible provider host. It provides supported, conditional, unsupported, and
read-only counts to make contract gaps visible.

It does not scan the endpoint, inspect authorization, verify TLS/certificates,
prove runtime availability, or change any provider configuration.
