# V1.6 Feature spec — clone și create-from-template

**Status:** implementat local, în validare și rollout

**Backlog livrat:** B032–B034

**Provideri:** Proxmox VE, VMware vSphere/ESXi, XAPI; Xen Orchestra și raw Xen explicit capability-blocked

## Outcome

Un administrator poate porni din `VM Catalog`, selecta un VM template și crea o VM nouă powered-off prin același contract comun. Orice submit este precedat de live preflight, plan hash, alegere de storage, confirmare prin numele exact, idempotency key, lock-uri, audit, provider task persistent și verificare în inventarul final.

## Surse oficiale validate

- [Proxmox VE API viewer](https://pve.proxmox.com/pve-docs/api-viewer/) și [Administration Guide](https://pve.proxmox.com/pve-docs/pve-admin-guide.pdf): `qemu/{vmid}/clone`, `newid`, full/linked clone, target node/storage și task UPID;
- [vSphere VirtualMachine.CloneVM_Task](https://developer.broadcom.com/xapis/vsphere-web-services-api/latest/vim.VirtualMachine.html) și [VirtualMachineCloneSpec](https://developer.broadcom.com/xapis/vsphere-web-services-api/latest/vim.vm.CloneSpec.html): folder, resource pool, datastore, `powerOn=false`, rezultat Task;
- [XAPI VM class](https://xapi-project.github.io/new-docs/xen-api/classes/vm/index.html) și [XAPI overview](https://xapi-project.github.io/xen-api/overview.html): `VM.clone`/`VM.copy` urmate de `VM.provision`, cu task-uri async;
- [Xen Orchestra template workflow](https://docs.xen-orchestra.com/vm-templates), [REST RBAC](https://docs.xen-orchestra.com/xo6/acl-v2) și [controllerul REST oficial](https://github.com/vatesfr/xen-orchestra/blob/master/%40xen-orchestra/rest-api/src/vm-templates/vm-template.controller.mts): catalogul există, dar controllerul curent nu expune încă o acțiune de instantiate pe `vm-template`.

## Scope livrat

- capability `vm.create` și `vm.clone` devine conditional numai unde există un write workflow demonstrabil;
- API:
  - `POST /api/providers/:hostId/artifacts/:artifactId/clone/preflight`;
  - `POST /api/providers/:hostId/artifacts/:artifactId/clone`;
- operație durabilă non-idempotentă `vm.provision`, resource kind intern `artifact`;
- feature flag `DD_PROVIDER_VM_PROVISIONING=false` implicit;
- nume portabil 1–80 și clone mode `auto|full|linked`;
- storage candidate list cu canonical `ddr_storage_*`; native placement rămâne server-side;
- VM-ul nou rămâne powered-off; start-ul este o operație separată;
- Proxmox full/linked QEMU template clone și UPID reconciliation;
- vSphere full clone cu `CloneVM_Task`, folder/resource pool/source datastore default sau datastore explicit;
- XAPI linked `Async.VM.clone` sau full `Async.VM.copy`, urmat de un stage persistent `Async.VM.provision`;
- Activity Center leagă operația de catalog, fără să expună MoRef/OpaqueRef/UPID;
- recovery fără replay după timeout/restart: task polling sau căutare exactă a VM-ului țintă.

## Anti-scope

- ISO/bare VM create, LXC create și image upload/import;
- cloud-init, Sysprep și guest customization — V1.7;
- linked clone vSphere — necesită snapshot lifecycle/relocate semantics separate;
- start automat, multi-VM și bulk provisioning;
- XO JSON-RPC/websocket fallback ghicit; integrarea va fi activată numai după un endpoint oficial de instantiate sau un client XO task-safe dedicat;
- raw `xl/xm` provisioning;
- template versioning/promotion B042–B043 — batch separat după V1.7.

## Acceptance

1. preflight refreshuiește template, VM, storage și capability inventory;
2. submit-ul cere admin, host `operate`, writeable mode, plan hash curent, `confirm=true`, numele exact și Idempotency-Key;
3. referințele providerului nu apar în request, response, audit sau events;
4. mutation-ul nu este retrimis automat după răspuns întrerupt;
5. XAPI păstrează distinct stage-urile clone, provision-ready, provision-submit și provision-task și poate continua după restart fără replay;
6. succesul cere VM țintă unică în inventar, cu canonical `ddr_vm_*`;
7. feature flag OFF lasă preflight inspectabil, dar blochează submit;
8. provider/task timeout nedeterminabil se termină `unknown`, cu lock păstrat pentru rezoluție manuală.
