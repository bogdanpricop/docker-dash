# V4.4a — IP address evidence inventory feature specification

**Status:** planned for v8.33.0 (2026-07-28)

The host-view `GET /api/providers/:hostId/ip-address-inventory` collects
provider-visible/guest-tools NIC address observations from at most 100 VMs,
using four concurrent hardware reads and returning at most 1,000 addresses.
Incomplete NIC reads remain explicit coverage evidence.

This is not IPAM or active discovery: it does not query DHCP/IPAM, send packets,
run guest commands, or infer allocation or reachability. It performs no network
mutation, CLI fallback or remediation.
