# V3.8 — DR objectives and provider security assurance rollout results

## Scope

The release candidate covers exactly B149–B158. B149/B150 extend the existing
DR protection-group/runbook surface. B151–B158 add versioned, imported or
provider-reported security assurance without releasing a new provider mutation.

## Current result

- DR overview exposes workload RPO/RTO objective counts and non-disruptive test
  readiness with bubble-network, temporary-clone and cleanup boundaries;
- security packs cover Secure Boot, vTPM, encryption, confidential compute and
  hardening evidence without treating missing evidence as compliant;
- key-provider records accept only symbolic secret references and perform no
  health probe;
- confidential VM preflight is persistent, hash-bound, expiring and never
  authorizes VM creation;
- all collection and provider-mutation capabilities remain fail-closed and the
  assurance feature is default-off.
